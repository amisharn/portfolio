## BinBahadur - Smart Waste Classification

### Description

BinBahadur is a smart waste management application developed for our final year group project. The application uses a MobileNetV2 image classification model to identify different categories of waste and encourage proper waste disposal.

The project combined mobile application development with computer vision to create an AI-powered solution for waste segregation.

### Skills Demonstrated

- Transfer Learning
- Image Classification
- Mobile AI Integration
- Team Collaboration
- Rapid Prototyping

### Technologies

- TensorFlowLite
- MobileNetV2
- Flutter
- Python
